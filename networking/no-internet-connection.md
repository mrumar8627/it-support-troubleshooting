# No Internet Connection Troubleshooting

## Problem

A computer cannot access the internet.

## Possible Causes

- Wi-Fi is disconnected
- Ethernet cable is disconnected
- Network adapter is disabled
- Incorrect IP configuration
- Router or access point problem
- DNS problem
- Internet service problem

## Troubleshooting Steps

### 1. Check the Physical Connection

For Ethernet:

- Check whether the network cable is connected properly.
- Try another network cable if available.

For Wi-Fi:

- Check whether Wi-Fi is enabled.
- Check whether the computer is connected to the correct network.

### 2. Check Network Status

Open Windows network settings and check the connection status.

Confirm whether the computer has a network connection.

### 3. Check IP Configuration

Open Command Prompt and run:

```cmd
ipconfig
