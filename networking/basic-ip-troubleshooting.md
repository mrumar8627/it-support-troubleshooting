# Basic IP Troubleshooting

## Purpose

This guide documents basic IP configuration checks on a Windows computer.

## What Is an IP Address?

An IP address identifies a device on a network.

Example:

192.168.1.20

## What Is a Subnet Mask?

A subnet mask helps identify the network and device portions of an IP address.

Example:

255.255.255.0

## What Is a Default Gateway?

The default gateway is normally the network device used by a computer to communicate with other networks.

Example:

192.168.1.1

## What Is DNS?

DNS (Domain Name System) translates domain names into IP addresses.

For example:

google.com → IP address
