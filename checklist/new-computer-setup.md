# New Computer Setup Checklist

## Hardware Setup

- [ ] Check the physical condition of the computer
- [ ] Connect the monitor
- [ ] Connect the keyboard
- [ ] Connect the mouse
- [ ] Connect the power cable
- [ ] Check all required cables and connections

## Operating System

- [ ] Start the computer
- [ ] Complete Windows setup
- [ ] Check system information
- [ ] Install Windows updates
- [ ] Restart the computer if required

## Software Setup

- [ ] Install required software
- [ ] Verify software installation
- [ ] Configure required applications
- [ ] Remove unnecessary software if required

## Network Setup

- [ ] Connect the computer to Wi-Fi or LAN
- [ ] Check network connection
- [ ] Check IP configuration
- [ ] Test internet connectivity

## Peripheral Testing

- [ ] Test keyboard
- [ ] Test mouse
- [ ] Test monitor
- [ ] Test printer if required
- [ ] Test other required peripherals

## User Setup

- [ ] Create or configure the user account
- [ ] Verify user access
- [ ] Configure required user settings

## Final Check

- [ ] Confirm Windows is working correctly
- [ ] Confirm required software is working
- [ ] Confirm network connectivity
- [ ] Confirm peripherals are working
- [ ] Document any remaining issues

## Completion

The computer is ready for use after all required setup and testing steps are completed.
