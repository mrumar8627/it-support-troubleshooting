# Computer Lab Maintenance Checklist

## Hardware Check

- [ ] Check computer systems
- [ ] Check monitors
- [ ] Check keyboards
- [ ] Check mice
- [ ] Check power cables
- [ ] Check network cables
- [ ] Check printers
- [ ] Check projectors
- [ ] Identify faulty equipment

## Software Check

- [ ] Check Windows updates
- [ ] Check required applications
- [ ] Check available storage
- [ ] Check basic system functionality
- [ ] Identify software-related problems

## Network Check

- [ ] Check LAN/Wi-Fi connectivity
- [ ] Test internet access
- [ ] Identify computers with network problems
- [ ] Check basic network configuration when required

## Computer Testing

- [ ] Start selected computers
- [ ] Test keyboard and mouse
- [ ] Test monitor
- [ ] Test required applications
- [ ] Test internet connection

## User Support

- [ ] Record reported technical problems
- [ ] Perform basic troubleshooting
- [ ] Test the system after troubleshooting
- [ ] Document unresolved problems
- [ ] Escalate problems requiring further technical support

## Documentation

- [ ] Record hardware problems
- [ ] Record software problems
- [ ] Record network problems
- [ ] Record maintenance performed
- [ ] Update issue records when required

## Final Check

- [ ] Confirm computers are ready for use
- [ ] Confirm required software is available
- [ ] Confirm network connectivity
- [ ] Confirm peripherals are working
- [ ] Record any remaining issues

## Goal

Maintain reliable and usable computer lab systems for students and staff.
