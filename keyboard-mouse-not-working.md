# Keyboard and Mouse Not Working

## Problem

The keyboard or mouse is not responding.

## Possible Causes

* Loose connection
* Damaged USB port
* Faulty keyboard or mouse
* Driver problem
* Wireless battery problem
* USB connection issue

## Troubleshooting Steps

1. Check the connection.
2. Try another USB port.
3. Test the device on another computer.
4. For wireless devices, check the batteries.
5. Restart the computer.
6. Check whether Windows detects the device.
7. Replace the device if hardware failure is confirmed.

## Result

The problem can usually be identified by testing the peripheral, USB port, and connection separately.

## Lesson Learned

Testing the same device on another computer helps determine whether the problem is related to the peripheral or the computer.
