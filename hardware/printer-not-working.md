# Printer Not Working

## Problem

The printer does not print the requested document.

## Possible Causes

- Printer is powered off
- Connection problem
- Paper is not available
- Ink or toner problem
- Printer is offline
- Print queue contains an error
- Driver problem

## Troubleshooting Steps

1. Check printer power.
2. Check paper and ink/toner.
3. Check USB or network connection.
4. Check printer status in Windows.
5. Check the print queue.
6. Cancel stuck print jobs if necessary.
7. Restart the printer.
8. Test printing again.
9. Check the printer driver if the problem continues.

## Result

The problem should be isolated by checking power, connection, printer status, queue, and drivers.

## Lesson Learned

Printer troubleshooting should start with simple physical checks before software configuration.
