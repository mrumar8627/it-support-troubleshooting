# Computer Not Turning On

## Problem

The computer does not power on when the power button is pressed.

## Possible Causes

* Power cable is disconnected
* Power socket has no electricity
* Power supply problem
* Loose internal connection
* Power button problem
* Hardware failure

## Troubleshooting Steps

### 1. Check the Power Connection

* Check whether the power cable is connected properly.
* Check the power socket.
* If possible, test another working socket.

### 2. Check the Power Cable

Inspect the cable for visible damage and make sure it is firmly connected.

### 3. Check for Power Indicators

Check whether:

* Power LEDs are working
* Fans are spinning
* Any sound is coming from the computer
* The monitor receives power

### 4. Perform a Basic Power Reset

* Turn off the power.
* Disconnect the power cable.
* Wait for a short period.
* Reconnect the cable.
* Try starting the computer again.

### 5. Check External Devices

Disconnect unnecessary USB devices and peripherals and try starting the computer again.

## Result

If the computer still does not turn on, the problem may require further hardware diagnosis or professional repair.

## Lesson Learned

Always begin troubleshooting with simple external checks before investigating internal hardware.
